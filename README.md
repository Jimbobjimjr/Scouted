# Scouted

A narrative choice game for the Valor Esports Communication Skills Level 2 course. Players are a newly scouted esports player, and every chat before, during and after a match shapes their career.

- Play: https://jimbobjimjr.github.io/Scouted/
- Story map (every choice, colour-coded): https://jimbobjimjr.github.io/Scouted/story-map.html

Each file is a single self-contained HTML page. Download either one and double-click it to play offline.
